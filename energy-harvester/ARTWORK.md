# ENERGY HARVESTER artwork

The approved direction is revision 3 of the design handoff, using **06-recirculation.png** throughout the decorative cycle. Historical 04/05 concepts are not later stages of the animation.

Assets/DeviceShell.png was generated using the Imagegen skill and the built-in image-generation tool on 1 October 2026, editing the approved ready-state concept into a blank production shell. It retains the translucent plasma-pink resin, exposed PCB, screws, dark screen, recessed central socket, two slider recesses and footer socket. Functional text, the button face/glyph, fader handles, values, progress and all animated lights are native JUCE drawing. The original generated shell has transparent exterior pixels and measures 1106 × 1422 pixels; its logical display is 560 × 720. A native-size shell is cached by the editor, without replacing the source artwork.

Generation direction: preserve the reference enclosure, camera, proportions and pink material; remove title, display lettering, chart, functional control faces, slider handles and labels; leave blank production sockets and glass; preserve alpha outside the enclosure; add no new knobs or control geometry. The generated PNG is embedded at build time; installed plugins read no loose images.

The six-second lighting loop is authored code, not a baked image sequence. Twelve irregular PCB routes carry moving current heads and short trails. Six scattered component pockets bloom; a thin 114.5-pixel socket contour wavers with periodic harmonics. Route glows and a small charge sprite are cached. Masks protect the title, screen, button face, slider fascia and INFO. The OFF state dims the shell; ON restores brightness and animated absorption. The truthful segmented ring is drawn separately from the decorative halo.

HARVEST ON attacks illumination in 120 ms; OFF releases it in 240 ms. Elapsed UI time drives the independent loop, including at clean AT SPEED. Reduced Motion is a static composition. Host bypass dims and freezes the lights. INFO suspends the decorative loop; hidden/inactive editors use a slower state poll, with no busy decorative 30 Hz work.

Chakra Petch SemiBold and BoldItalic come from the existing plugin family, with the supplied SIL Open Font License. The shared INFO component and approved VFD logo retain their original geometry and links. ENERGY has a local pink theme; no sibling themes or assets were changed.

Version 0.2 uses a new Imagegen robot icon, generated on 1 October 2026 from the existing THROW-UP and BACK-SCRATCH robot family references. It preserves the squat resin/PCB robot silhouette, ivory three-contact head, lightning eyes and block fists/feet, with plasma-pink resin and raised EH chest lettering. The original transparent 1280 × 1280 PNG is Assets/AppIcon.png. JUCE converts it to AppIcon.icns for the plugin and native installer. The suite installer shows each payload's existing icon in its row. Original generated file: exec-357050b9-797b-41d4-b402-5ed0e0586a39.png; Imagegen builtin tool, transparent_background true. The screen FX buttons and TIME/SYNC pill are native drawing; no enclosure artwork was altered. The screenshots and animated WebP in the release were captured from the implemented native editor, with a developer-only phase override. The WebP encodes 216 frames covering three exact six-second cycles. It is a deterministic renderer preview, not a DAW screen recording.

Version 0.3 adds a native JUCE ivory OUTPUT dial in the lower-left footer, beside INFO. A recessed plum mount, rose accent arc, Chakra Petch label and borderless pearl dB readout match the existing control materials. The enclosure bitmap and plugin icon are unchanged. The animation mask protects the complete output control.

Version 0.3.1 replaces the rectangular dark output panel with a circular molded resin socket drawn directly over the exposed footer PCB. A concentric rose bezel, inset collar, larger ivory cap and directional highlights echo the HARVEST and INFO sockets. OUTPUT and the borderless editable value sit directly on the board. The rotary center aligns with INFO. This refinement is native JUCE drawing; no new generated raster asset was used.
