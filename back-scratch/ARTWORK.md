# BACK-SCRATCH interface artwork — retained in 0.8

Version 0.8 retains the approved 0.7 bitmap. Its illuminated timing buttons, pattern-shift arrows, shifted graph and playback marker are drawn as native controls; no new image generation or bitmap edits were used for this update.

Created with the built-in image_gen tool in edit mode on 25 September 2026. The final project asset is `Assets/Interior-v7.png`; the original `Assets/Shell.png` remains intact. The live interface is implemented in `Source/BackScratchEditor.cpp`.

Input 1 was the original BACK-SCRATCH shell. Input 2 was the actual SHIFTY v0.2 editor screenshot. Input 3 was the actual YOI-BOI v0.1.3 Play screenshot. The latter two were material/style references only.

The generated artwork was inspected and the actual knob, button, display and plate positions were measured from the result. Live hit regions and rendering follow those actual positions, not the requested approximate coordinates below. The original amber light is also drawn unchanged from the original shell and checked against the rendered editor at the pixel level. Text, graphs, knob pointers, toggle state and meters remain real controls rendered by the plug-in.
