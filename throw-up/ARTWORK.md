# THROW-UP artwork — 0.1.1

`Assets/AppIcon.png` is the generated THROW-UP icon: a translucent tangerine-orange TU robot in the established YOI-BOI family. It was produced with the built-in image generation tool, using the existing SHIFTY icon as an edit reference. The generated PNG has a transparent background. The final file is stored inside this project, not only in the tool's generated-images folder. `Assets/AppIcon.icns` contains the macOS icon sizes.

The 0.1.1 editor uses `Assets/DeviceShell-v2.png`, a new transparent raster enclosure produced with the built-in image-generation tool. The edit target was the actual SHIFTY device shell; BACK-SCRATCH’s approved interior was a material reference. This replaces the earlier procedural landscape interface with a portrait hardware design from the same family. Live pointer marks, labels, values, preset selection and meters are native controls aligned to the actual artwork. The image is 1122 × 1402 RGBA; the visible editor crops the design rectangle (34, 18, 1058, 1360) while retaining transparent corners. The default editor is 660 × 848 pixels. The audio engine and icon are unchanged.

## Icon generation prompt

> Use case: precise-object-edit. Asset type: macOS audio plugin app icon, square 1024 x 1024 PNG cutout with actual transparent background. Edit this existing green YOI-BOI robot mascot to create its THROW-UP sibling. Preserve exactly the chunky blocky friendly robot silhouette, the 3D three-quarter front view, pose, cream slanted pixel eyes on the dark visor, three cream rectangular blocks on the head, cream joints, metallic screws, visible tiny circuit boards under the glossy translucent plastic shell, and whole robot comfortably inside frame with consistent margins. Change all green translucent shell material to rich luminous tangerine orange / clear amber acrylic, with bright warm highlights and deep burnt-orange thickness at edges. Replace the single cream 'S' chest lettering with exactly the two letters 'TU' in the same chunky cream pixel-block letter style centered together on the chest. No other text. Make it feel like high fidelity manufactured collectible music hardware. Keep background fully transparent; no background color, no stand, no drop shadow outside the robot, no watermark.

The built-in tool returned a 1254 × 1254 PNG, preserving transparency and the requested composition.
